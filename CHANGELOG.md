# Changelog

Qualestra follows semantic versioning after its first public release. Until then, entries describe
release candidates and may include contract changes.

## 0.1.0 — release candidate

- Supervised six-agent QA orchestration with deterministic policy and release gates.
- Portable project adapters, browser/API/invariant exploration, verification, evidence, and reports.
- Durable approval-gated report delivery with filesystem and no-op adapters.
- Server-configured GitHub Issues, Jira, and Slack delivery providers.
- Standalone container deployment, installable onboarding CLI, release checks, and provenance-ready
  tag automation.
- Apache License 2.0 declarations for the source, Python distribution, and container images.
